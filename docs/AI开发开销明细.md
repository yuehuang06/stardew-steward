## 单价推算

- 总花费 $18 ÷ 总 Token 134.3M ≈ $0.134 / 1M tokens（加权平均，含 cache 折扣）
- 清华平台套餐制，opencode 记录 cost=$0，实际费用通过平台充值消耗
- 注：cache read 占总量 93%，实际"新计算"的 token 仅 ~9M（input+output+reasoning）
